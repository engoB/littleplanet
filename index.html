L'histoire

Des météores pleuvent sur une galaxie de petits mondes. Ta DeLorean volante ne s'arrête jamais : fais le tour de chaque planète le plus longtemps possible, puis file vers la suivante grâce à l'étoile de lancement.

◀gauche▶droite

Piloter

Garde le doigt sur la moitié gauche ou la moitié droite de l'écran pour tourner. Le cercle de flammes en bas à droite, c'est le turbo : maintiens-le appuyé.

Éviter

Une cible rouge annonce l'impact d'un météore : écarte-toi. Évite aussi les cratères et les poteaux. Ta vie, c'est le fin cercle autour du véhicule.

RéparerTurbo pleinAccélérerSauter

Ramasser

Les caisses réparent, les baskets remplissent le turbo, les flèches accélèrent et les ressorts font sauter. Fonce dans les objets posés au sol : lancé à pleine vitesse, tu les envoies en orbite !

✓ 3/3Objectifs ●○○🔒

Progresser

Chaque monde a 3 objectifs : réussis-les pour débloquer le suivant (les mondes gris sont verrouillés). Le dernier monde ouvre le Voyage galactique et les défis ; tes succès 🏆 débloquent les autres.
